# Incoming reference packs

Upload temporary reference archives here.

Preferred archive name:

`Bellmont_reference_pack.zip`

The archive should already contain target-relative paths such as:

```
references/
  characters/
  locations/
```

After upload, the archive is treated as a staging artifact only. The individual images should be committed to their final folders and the archive removed from the current tree once the pack has been verified.
