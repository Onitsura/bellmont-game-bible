# Bellmont & Co. — точная карта реплик из GDScript 0.9.1-review

**Снимок:** `docs.zip`, 14.10.2026. **Тип данных:** статическое извлечение строк из исходников `.gd` без запуска Godot. **Статус:** реализованный текст, не автоматически утверждённый литературный канон.

В каждой реплике указан **реальный ID**, который вычисляет текущий скрипт для воспроизведения аудио. Варианты меню записаны отдельно от произносимых реплик. Текст из `intro.gd` отсутствует в пользовательском ZIP; по прологу сохраняется существующая карта `dialogue_current_build.md`, пока интро не будет независимо сверено с игровым репозиторием.

Для текстовых выводов осмотра предметов, сообщений дневника и подсказок действует иной источник: `lobby.gd`, `day2_controller.gd`, `day2_objects.gd` и др. Они **не являются** частью этого инвентаря озвучиваемых диалогов.
