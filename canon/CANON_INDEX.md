## Canon rules

- The current game build is authoritative for what is playable. Do not silently rewrite implemented dialogue.
- `expanded_game_skeleton.md` remains the master for **future** plot and gameplay structure; implementation details of Chapter 3 in v7.1 override its older Chapter 3 outline.
- Earlier plans or production briefs do not make unimplemented features playable. In particular, future third-floor scenes, financial calculations and the true journey of Nora are not yet in v7.1.
- Items explicitly listed as unresolved/open in the expanded skeleton remain undecided until approved.
- Visual reference files beat textual descriptions for faces and existing locations. Superseded drafts belong in `archive/obsolete/`.
