## Read order

1. `../CURRENT_STATE.md`
2. `expanded_game_skeleton.md` — master story/gameplay canon for the expanded game; chapters, investigation lines, locations, puzzle architecture and major discoveries.
3. `day1_anniversary_bridge.md` — detailed current Day 1 story plan and anniversary bridge. Exact implemented Day 1 details remain authoritative for the current build.

## Canon rules

- Current implemented game build and exact current dialogue beat planning documents for already implemented content.
- `expanded_game_skeleton.md` is the master authority for the expanded plot and gameplay structure from the current point forward.
- Where an older planning document conflicts with the expanded skeleton on future story structure, the expanded skeleton wins.
- Items explicitly listed as unresolved/open in the expanded skeleton remain undecided; do not invent them.
- Exact dialogue from the current build must not be silently rewritten.
- Visual reference files beat textual descriptions for faces and existing locations.
- Superseded drafts belong in `archive/obsolete/`.
